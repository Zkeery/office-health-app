# 工位行动

面向久坐上班族的响应式应用原型：滚动七日饮食计划 + 碎片运动 + 预算出餐 + 积分成就 + 会员。

餐单与会员使用演示数据，个人状态保存在浏览器 localStorage。地图接入高德 JS API 2.0，支持真实地点搜索、附近分类查询和用户主动定位；安全密钥通过 Vite 服务端代理注入。

## 如何运行

```bash
git clone https://github.com/Zkeery/office-health-app.git
cd office-health-app
npm ci
cp .env.example .env.local
npm run dev -- --host 127.0.0.1
```

使用 Node.js 24。浏览器打开 http://127.0.0.1:5173/。桌面使用宽屏布局，手机使用单列布局。

地图需要在 `.env.local` 填写自己的高德 Web端 Key 和安全密钥，并配置域名白名单，详见 [地图配置](docs/amap-setup.md)。不配置地图凭据也可使用其余页面。凭据文件不提交 Git。

```bash
npm run build
npm run preview
```

## 路由一览

| 路径 | 说明 |
|------|------|
| `/onboarding` | 引导：年龄段 / 久坐 / 外卖频率 / 预算 / 饮食备注 |
| `/` | 今日：餐单摘要、碎片运动、打卡 CTA、积分 |
| `/map` | 全屏高德地图、地点搜索、餐饮/咖啡/公园/运动分类 |
| `/week` | 七日滚动计划（非会员仅完整看近 3 天） |
| `/meals` | 出餐：预算 + 比例滑杆 + 生成/换餐 |
| `/exercise` | 完整时长分段指导、暂停/继续、完成确认与手动补记 |
| `/me` | 编辑档案并更新未确认计划、积分、周成就、会员入口、重置引导 |
| `/membership` | 会员付费墙（模拟开通写入 localStorage） |
| `/checkin` | 打卡反馈页（首页也可用弹层） |

底部 Tab：**今日 | 七日 | 出餐 | 运动 | 地图 | 我的**

## 关键路径

1. 完成引导 → 进入「今日」
2. 「出餐」生成三餐 → 换一餐 / 确认用餐（积分 Toast）
3. 「运动」完成一项 → 积分增加
4. 首页「立即打卡」→ 提交反馈
5. 「我的」→「会员」模拟开通（积分加倍）

## 计划与记录规则

- 日预算为 20–300 元，生成与换餐不放宽总预算；三餐比例是偏好。
- 素食指蛋奶素，另支持纯素与不辣，可组合。超出支持范围的备注保留原文并暂停推荐，不猜测是否满足。菜品为模拟配方，不代表真实商家食材。
- 无可行三餐时显示原因与示例菜单最低预算。旧餐单加载时保留并校验，不合规餐单提示调整路径。
- 档案编辑和出餐保存共用日预算；重生成只更新未确认餐次。已确认餐次不能换餐或重复领奖；跨日旧餐单归档至 `mealHistory`，历史积分、打卡、运动保持。
- 金额为计划参考价，不记录实际支付。按时吃饭和精力必须主动选择，运动记录会被反馈复用。
- 运动计时与卡片时长一致，包含热身/动作/休息；离页结束计时，不自动记完成。手动补记需确认已实际完成，同项运动每日只记一次。

## 发布说明

GitHub 仓库保存源码，不等于网站已上线。地图依赖 `/api/maps/config` 和 `/_AMapService/` 服务端代理；不能只把 `dist` 上传到 GitHub Pages 就获得完整地图能力。正式托管时需要配置等效服务端代理和部署环境变量。
